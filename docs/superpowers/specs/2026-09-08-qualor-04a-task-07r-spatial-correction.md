# QUALOR Task 07R: Spatial Intelligence Instrument

Owner-authorized presentation correction, 2026-09-08, additive to the
[approved workspace design](2026-09-07-qualor-04a-decision-intelligence-workspace-design.md).

This supersedes Task 7's olive-toned, serif-led marketing-hero interpretation.
The owner did not accept that visual result. The generated planetary mockup is
not a design authority. Spatial means a stable working scene, precise alignment
and distinct information layers, without space illustrations or simulated data.

The owner's subsequent visual addendum explicitly rejects merely recoloring the
old headline/CTA/decorative-rail composition. The central surface must carry
operational state and truthful context. Orbits, gauges, glowing rings, radar and
decorative metric dials are prohibited. Manrope is the Phase A candidate, not an
irrevocable brand choice; an unsuitable result must be reported rather than
silently replaced with an arbitrary font.

The approved correction uses neutral carbon (`#0D0E0F`), a decision surface
(`#141516`), contextual depth (`#1B1C1E`), readable neutral text (`#F2F3F5`,
`#BAC0C8`), restrained selection/focus (`#BDD8EE`) and local Manrope at
400/500/600. Light proof material remains `#F1F0EB`; it is a document layer,
not a theme toggle or a mandatory percentage of each screen. Standard controls
do not borrow the paper color.

The 1440px starting geometry is a 64px header, 256px opportunity region,
288px context rail and a dominant remaining decision stage. Context, state,
facts and action share alignment axes. At narrow widths the active working
state precedes supporting context. Portfolio retains its existing fields,
version protection, provenance and UNKNOWN semantics with practical grouping.

Core information architecture, deterministic authority, local API security,
human approval and the prohibition on external submission are unchanged.
No Tasks 8–10 behavior is authorized. The 04A/04B division remains intact.

Phase A produces real local-API empty workspace and Portfolio screenshots,
plus a separate development-only populated proof using the existing D02
synthetic decision fixture and deterministic evaluator output. Its permanent
label is `DESIGN PREVIEW · SYNTHETIC FIXTURE · READ ONLY`; it has no approval
actions, live calls or production route. This tests content geometry without
asserting live competition facts.

Phase A ends with focused frontend tests/build and actual browser proof.
Owner visual acceptance is pending. No commit, push, merge or Task 8 execution
occurs before that checkpoint. Phase B requires explicit owner approval of
the screenshots before final verification and the separate final review.
