# 0003: Live evidence has separate observation and decision boundaries

Date: 2026-09-06. Task: QUALOR-03B3. Canonical specification:
`docs/00_CANONICAL_BRIEF_UA.md` (unchanged).

One Strands 1.54.0 Agent plans information gathering through four bounded tools.
It receives no shell, file, browser, IAM or verdict-setting tool. The operator supplies
the authorized official-source host registry and explicit synthetic studio facts.
Search and fetched source content are untrusted observations, including instructions
embedded in them. Model prose and reasoning are discarded, not used as decisions.

## Admission and authority

Pydantic constrains claim fields, states, excerpts and source references. Code requires
a source fetched during this run, a matching URL and a literal normalized quote.
Values unsupported by that quote are rejected. N/A needs an explicit quoted reason.
Only a small controlled-clause policy can mark simple technology/new-project clauses
reviewed. Partial product names, unrelated subjects, conditions, alternatives and
negations cannot qualify. Other extracted clauses remain QUOTE_ONLY/UNKNOWN.
Source qualification checks do not depend on model-selected quote punctuation; any
qualification/negation in a source conservatively prevents automatic clause review.
This is deliberately not a general legal interpretation or date-normalization engine.

Third-party sources and snippets cannot establish reviewed critical evidence.
Disagreeing official candidate values force unresolved critical rules; no model chooses
the convenient source. Equivalent scalar/list representations are normalized;
positive technology requirements are additive. Different values in other categories
remain conservatively unresolved. Genuine critical contradictions suspend definitive
rule conclusions until an explicit precedence/applicability policy can resolve them.

The original eligibility and recommendation algorithms remain the final authority.
`DecisionInput`/`DecisionOutput` and `EvaluationInput` carry the real run mode; strict
fixture subclasses still reject LIVE/REPLAY forgery. Missing legal coverage, project
matching requirements, costs and external competition rules remain unknown. A live
run may therefore produce conditional project results and an unresolved portfolio.

## Network and spend

The fetcher resolves approved HTTPS hosts, rejects every non-public answer, and
connects to a vetted numeric address while preserving the original TLS hostname/SNI.
Each redirect is checked again. Certificate validation stays enabled. An active timer
interrupts slow header/body reads through the captured TLS socket. Responses and
redirects are bounded; HTML scripts/styles are excluded. Full pages stay in run memory.

One shared sequential reservation guard applies before physical model/search/fetch
operations. The task-specific policy allows six model calls, five searches and ten
documents within USD 0.20; earlier bootstrap defaults remain unchanged. A conservative
UTF-8 byte estimate plus framing and capped output bounds each model reservation.
Returned usage reconciles the reservation downward; failures retain it. SDK and
Strands automatic retries are disabled. The exclusive local run marker prevents
silent repeated paid runs after interruption. It is an operator development safeguard,
not cross-machine billing enforcement.

Bedrock global Sonnet 4.6 estimates use USD 3/input-million and USD 15/output-million
tokens from the [official vendor pricing table, AWS Bedrock section](https://www-cdn.anthropic.com/files/4zrzovbb/website/3684c2faafb97418665782cea0001f439f74b1d2.pdf).
Search attempts reserve USD 0.009 including Gateway overhead. Estimates are not bills.
